BlockCore - Blockprogrammierung fuer Arduino, lokal unter Windows
=================================================================

BlockCore laeuft komplett auf diesem Computer. Es braucht kein Internet,
keinen externen Server und kein Connector-Programm.

Unterstuetzte Boards: Arduino Uno, Arduino Nano, Arduino Mega
(mit Farbsensor TCS34725 und L293D-Motor-Shield).

So geht's
---------
1. "BlockCore" starten (Desktop oder Startmenue).
   Nach einem kurzen Startfenster oeffnet sich das BlockCore-Fenster.
2. Den Arduino per USB anschliessen.
3. In BlockCore: "Roboter -> Verbinden" und den COM-Port waehlen.
   Ist nur ein Arduino angeschlossen, wird er automatisch gewaehlt.
4. Programm bauen und auf "Ausfuehren" (Play-Knopf) klicken.
   Das Programm wird kompiliert und auf den Arduino geladen.
5. Ausgaben des Arduino ("zeige auf Serial Monitor") siehst du unter
   "Roboter -> Serieller Monitor". Beim Hochladen pausiert der Monitor
   automatisch und verbindet sich danach wieder.
6. Zum Beenden das BlockCore-Fenster schliessen.

Das Board (Uno, Nano, Mega) waehlst du unter "Roboter -> Board", die Sprache
unter "Sprachen". Programme werden automatisch auf diesem PC gespeichert.

Probleme?
---------
- Kein COM-Port zu sehen: Viele guenstige Arduino-Nachbauten brauchen den
  USB-Treiber "CH340" (Suche: "CH340 Treiber Windows").
- Upload schlaegt fehl: Ist der richtige COM-Port gewaehlt? Benutzt ein anderes
  Programm (z. B. die Arduino IDE) den Port? Beim Nano mit altem Bootloader
  wird automatisch auch die langsamere Uebertragung probiert.
- Die Programme liegen in %LOCALAPPDATA%\BlockCore,
  das Server-Log in %LOCALAPPDATA%\BlockCore\logs\server.log.

BlockCore ist nur auf diesem Computer erreichbar (http://127.0.0.1:1999).
